# CERVIRON

Двуязычный Статический двуязычный сайт продукта CERVIRON.

- По умолчанию открывается румынская версия: `ro/index.html`.
- Русская версия находится в `ru/`.
- Стили уже готовы в `css/style.css`; сборка, SCSS и внешние зависимости не требуются.
- Изображение продукта: `img/cerviron_img.png`.

## Структура классов

Вёрстка использует BEM без препроцессоров: самостоятельные блоки (`.header`, `.nav`, `.hero`, `.card`, `.product`, `.footer`), их элементы (`.hero__image`, `.header__inner`, `.card__number`) и модификаторы (`.button--primary`, `.nav--open`). Класс `.container` — только вспомогательный класс для ограничения ширины контента.

Для просмотра откройте `index.html` через любой статический сервер или в браузере.

## Настройки сервера: папка `includes/`

Всё, что отличается от сервера к серверу, лежит в папке `includes/`. Страницы подключают эти файлы через Apache SSI (`<!--#include virtual="..." -->`), сами страницы менять не нужно:

- `includes/site-url.txt` — адрес сайта без слеша в конце, например `https://cerviron.punct.one`. Подставляется в ссылки `canonical` и `hreflang`. В файле должна быть одна строка без переноса в конце;
- `includes/head.html` — подключается в `<head>` каждой страницы (основной код Google Tag Manager, скрипты аналитики);
- `includes/body.html` — подключается сразу после `<body>` (блок `<noscript>` от GTM, виджеты).

Папки `includes/` и `includes.example/` (локальные образцы этих файлов) добавлены в `.gitignore`: в репозитории их нет, и обновления их не перезаписывают. На сервере файлы создаются один раз вручную. Если какого-то файла нет, страница открывается как обычно, только без вставки.

SSI включается в `.htaccess`, на хостинге должен работать модуль `mod_include`. При локальном просмотре через Live Server вставки не выполняются, это нормально.
